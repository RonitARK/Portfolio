# Ronit Gupta — Portfolio

A personal portfolio showcasing my work across **development, UI/UX, art, film, and creative projects**.

Built with Next.js, TypeScript, Tailwind CSS, and Sanity CMS.

## Explore

- **About** — Learn more about me
- **Development** — Explore my software projects
- **UI/UX** — View design and product work
- **Art** — Discover my creative work
- **Film** — Explore film and visual projects
- **Blogs** — Read my thoughts and articles
- **Contact** — Get in touch

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Sanity CMS
- Framer Motion

## Run Locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000) to view the portfolio.
